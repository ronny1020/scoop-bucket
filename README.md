# ronny1020/scoop-bucket

Scoop manifests for my own projects.

```powershell
scoop bucket add ronny1020 https://github.com/ronny1020/scoop-bucket
scoop install muster
```

[Muster](https://github.com/ronny1020/muster) is unsigned, so SmartScreen may
warn on first run. It installs for the current user and needs no admin rights.
